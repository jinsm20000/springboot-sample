Spring Boot 간단 샘플 앱

준비: JDK 17 이상, Maven 3.6.3 이상 설치

Windows PowerShell 또는 CMD에서 프로젝트 폴더로 이동:
  mvn spring-boot:run

브라우저에서 접속:
  http://localhost:8080/

예상 표시 문구:
  Spring Boot sample is running!

종료: 실행 창에서 Ctrl+C

구조:
  pom.xml: 프로젝트 의존성 및 빌드 설정
  DemoApplication.java: 애플리케이션 시작 및 GET / 요청 처리

실행 화면을 직접 캡처하여 학습 기록으로 남길 수 있습니다.
